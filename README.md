# RikkaHub APK 下载

本仓库**仅提供编译好的 APK**，方便直接下载安装。

> 源码仓库为私密仓库，本仓库不含任何源代码。

## 下载

前往 [Releases](../../releases) 页面下载最新版本。

- 推荐 `rikkahub-*-universal.apk`（全 ABI，兼容所有设备）
- 主流手机可用 `rikkahub-*-arm64-v8a.apk`（体积更小）

## 安装

1. 下载 APK 到手机
2. 允许「安装未知来源应用」
3. 安装后即可使用

**注意**：本包为自签名构建，若你已安装官方渠道版本，需先卸载再安装（签名不同）。
